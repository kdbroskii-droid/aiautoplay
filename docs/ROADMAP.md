# Roadmap

## Current architecture

The project now has action handling, feedback, history, learning, sandboxing, vision interfaces, policies, memory, training, rewards, storage, telemetry, core state/events, Chromebook diagnostics, observations, evaluation, CLI tools, examples, tests, and CI.

## Next engineering targets

1. Improve the deterministic sandbox.
2. Add richer observation adapters for user-owned environments.
3. Expand reward detectors and test coverage.
4. Add a terminal dashboard for training metrics.
5. Profile CPU and memory usage on Chromebook hardware.
6. Keep environment adapters separate from any public-game automation.
